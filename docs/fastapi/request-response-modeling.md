# Request / Response Modeling

## 왜 중요한가

FastAPI에서 schema 설계는 곧 API 계약 설계다. Pydantic과 serialization 경계를 정확히 이해해야 한다.

## 이 장에서 채울 것

- input model vs output model
- response model filtering
- `Annotated` metadata
- validation boundary
- serialization 전략

## 실전 연결

- public API contract
- internal DTO 분리
- backwards-compatible response 설계
