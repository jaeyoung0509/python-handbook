# Decorators

## Why It Matters

Decorators are a powerful abstraction, but they also hide call signatures, add wrapper costs, and can make debugging harder when used carelessly.

## This Chapter Builds

- function decorators vs class decorators
- closure and wrapper overhead
- `functools.wraps`
- typing with `ParamSpec`
- common decorator overuse patterns

## Practical Connections

- FastAPI route decorators
- dependency helpers
- logging, tracing, and caching wrappers
