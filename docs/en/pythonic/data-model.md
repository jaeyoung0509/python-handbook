# Data Model

## Why It Matters

Python feels coherent once you realize that functions, methods, operators, and attribute access are all expressions of the data model.

## This Chapter Builds

- object identity, type, and value
- attribute access and method binding
- how dunder methods connect to syntax
- the difference between `__getattribute__`, `__getattr__`, and `__setattr__`

## Practical Questions

- Why is `len(obj)` not `obj.len()`?
- Why does a function become a bound method on a class?
- Why do framework fields start behaving magically after simple declarations?
