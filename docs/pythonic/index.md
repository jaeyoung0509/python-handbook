# Pythonic

이 파트는 "Python답게 생각하고 설계하는 법"을 다룬다.

## 이 파트에서 다루는 것

- data model
- attribute lookup
- descriptor
- property
- decorator
- context manager
- metaclass

## 왜 먼저 읽어야 하나

FastAPI, Pydantic, SQLAlchemy는 전부 Python data model 위에 서 있다. metaclass나 descriptor를 모르고 framework를 보면 "마법"처럼 느껴진다.
