# Decorators

## 왜 중요한가

decorator는 Python의 함수/클래스 확장 방식에서 가장 자주 쓰이는 도구다. 하지만 편한 만큼 타입과 introspection을 망치기 쉽다.

## 이 장에서 채울 것

- function decorator vs class decorator
- closure와 wrapper 비용
- `functools.wraps`
- typing과 `ParamSpec`
- decorator 남용 패턴

## 실전 연결

- FastAPI route decorator
- dependency injection helper
- logging / tracing / caching decorator
