# Typing

이 파트는 Python 3.14 기준으로 typing을 다시 잡는다.

## 이 파트의 목표

- typing을 문법 암기가 아니라 API 설계 도구로 이해한다.
- 정적 타입과 런타임 validation의 경계를 구분한다.
- FastAPI, Pydantic, SQLAlchemy가 typing을 어떻게 소비하는지 연결한다.
