# Modern Typing

## 왜 중요한가

요즘 Python 회사에서는 typing이 선택사항이 아니라 기본 전제인 경우가 많다.

## 이 장에서 채울 것

- `X | Y`
- `type` alias
- `Annotated`
- `Literal`
- `Self`
- `Never`
- modern built-in generic syntax
