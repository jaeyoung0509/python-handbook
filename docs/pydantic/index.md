# Pydantic

이 파트는 Pydantic v2를 "모델 선언 라이브러리"가 아니라 "validation engine" 관점에서 읽는다.

## 이 파트의 목표

- BaseModel 사용법을 넘어서 pydantic-core 감각을 잡는다.
- validation과 serialization이 어떤 파이프라인으로 동작하는지 이해한다.
- FastAPI와 typing/runtime boundary를 정확히 본다.
