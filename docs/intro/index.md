# Intro

이 파트는 이 사이트 전체를 어떻게 읽어야 하는지, 그리고 왜 "Python 3.14 handbook" 구조로 바꾸는지가 중심이다.

## 이 파트의 역할

- 기존 `버전별 변경점 정리`를 `주제별 학습 체계`로 연결한다.
- Pythonic, typing, runtime, asyncio, FastAPI, Pydantic, SQLAlchemy 2.0이 어떻게 이어지는지 보여준다.
- 처음 들어온 사람이 어디서부터 읽어야 하는지 안내한다.

## 이 파트에서 잡아야 할 감각

- Python을 "문법만 있는 스크립트 언어"로 보지 않는다.
- typing, runtime, framework를 하나의 생태계로 본다.
- Python 3.14는 기준선이고, 핵심은 주제별 깊이다.
